# Arcade

A collection of browser games written in vanilla HTML, CSS, and JavaScript. Each game runs independently in its own folder with its own styles and scripts. No frameworks, no build tools, no dependencies.

**Games:**
- Flappy Bird — fly through pipes. Controls: SPACE to jump, W to restart
- Snake — eat food, avoid walls and yourself. Controls: Arrow keys or WASD
- Breakout — smash bricks with a bouncing ball. Controls: Arrow keys to move, SPACE to shoot
- Asteroid Dodge — dodge space rocks. Controls: Arrow keys or WASD to move, SPACE to shoot, SHIFT for flare ring (3s cooldown)
- Pac-Man — chomp pellets, avoid ghosts, eat power pellets to turn the tables. Controls: Arrow keys or WASD to move, SPACE to start
- 2048 — slide tiles, merge numbers, reach 2048. Controls: WASD / ARROWS
- Space Invaders — defend Earth from enemy waves. Controls: WASD / ARROWS + SPACE
- Tetris — rotate and drop tetrominoes. Clear lines. Controls: WASD / ARROWS + SPACE
- Traffic Dodge — top-down car dodger. Steer left and right, dodge car doors, tyres, and debris. 3 hits and you are out. Count dodges for score. Controls: WASD / ARROWS
