# Contributing

Thanks for checking this out. Here's how to get involved:

## Running locally

Clone the repo and open `index.html` in a browser. That's it — no build step, no dependencies.

## Making changes

1. Fork the repo
2. Create a branch (`git checkout -b my-fix`)
3. Make your changes
4. Test locally before committing
5. Push the branch and open a PR

## What to build

Games! The arcade is always looking for more. Each game lives in its own folder with `index.html`, `styles.css`, and `script.js`. Check the existing games for the structure.

## Questions?

Open an issue and I'll get back to you.
